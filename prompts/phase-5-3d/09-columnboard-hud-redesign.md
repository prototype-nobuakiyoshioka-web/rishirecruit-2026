# Phase 5 Task 09: コラム看板をHUDバッジ風に再デザイン

## 問題

現在のコラム看板は木製のスキュアモーフィックなデザインで、
周囲のフラットで洗練されたUI(Header / エリアパネル / ピン)から浮いている。

## 目的

ゲームのHUD(Heads-Up Display)にあるようなバッジ風デザインに変更し、
現在の世界観に馴染ませる。

## デザイン方針

### 参考にする既存UIのトーン

| 要素 | 特徴 |
|---|---|
| Header | 暖白の半透明カプセル、角丸full、ソフトシャドウ |
| エリアパネル | 白の半透明、角丸lg、backdrop-blur |
| 3Dピン | 白のリング、ミニマル |

これらと同じ視覚言語を使いつつ、
**ゲームUIらしい要素**を加える。

### ゲームUIらしさの要素(参考)

以下のような要素を検討する(すべて使う必要はない):

- 半透明の背景 + backdrop-blur(ガラス質感)
- 細い枠線(border)で輪郭を強調
- アイコン + ラベルの組み合わせ
- 小さなバッジやインジケーター
- ホバー/タップ時のグロー効果や拡大
- 角丸だが完全な円ではない(スクエア寄り)

### 避けるべき表現

- 木目・立体的な影・グラデーションによる質感表現
- 過度に装飾的な要素
- 現在のような「物体」を模したデザイン

## 要件

| 項目 | 要件 |
|---|---|
| 配置 | 画面左下(現状と同じ) |
| サイズ | PC: 現状の70〜80%程度 / SP: さらに小さく |
| 表示内容 | 「コラム」+ 補足で「NOTE」 |
| アイコン | 記事・ノートを想起させるシンプルなアイコン(SVG) |
| 遷移先 | /columns(現状と同じ) |
| ホバー | 視覚的フィードバックあり |
| 背景 | 半透明 + backdrop-blur |

## 実装の自由度

具体的なデザイン(色・サイズ・アイコンの形状・レイアウト)は
実装者の判断に委ねる。

ただし以下は守ること:
- デザイントークン(docs/04-design-tokens.md)の値を使う
- 外部アイコンライブラリを追加しない(インラインSVGで完結)
- 既存UIとトーンが揃っていること

## 制約

### 変更してよいファイル
- components/scene/ColumnBoard.tsx

### 変更してはいけないファイル
- 上記以外すべて

### 絶対に守ること
- 配置(左下)を変えない
- /columns への遷移機能を維持する
- aria-label などアクセシビリティ対応を維持する
- タップ領域を44px以上確保する
- SP時に他要素と重ならない
