# Phase 5 Task 08e-3: SP時のカルーセル構造をPC版と揃える

## 問題

SP表示のカルーセル構造がPC版と異なっている。

現状:
- タブとエリア情報カードが分離している
- カルーセル1枚目がエリア情報カードになっている

## 目的

PC版と同じ構造にしつつ、SP向けの横スクロールを維持する。

## 目標構造
    ┌───┬─────┬─────┐
    │Job│Event│Spot │  ← タブ(PC版と同じ位置)

┌───────┴───┴─────┴─────┴──┐
│ ← [エリア情報] [投稿1] [投稿2] → │ ← 横スクロール
└──────────────────────────┘


### 要件

- タブ(Job/Event/Spot)はカルーセルの**上**に配置
- タブのデザイン・挙動はPC版と同じ
- カルーセルの**左端にエリア情報カード**を固定配置
- エリア情報カードの右に、選択中タブの投稿カードが並ぶ
- タブを切り替えると投稿カードのみ入れ替わる
- エリア情報カードはタブ切替で変わらない
- 横スワイプでスクロール、scroll-snap で吸着

## 制約

### 変更してよいファイル
- components/scene/AreaSidePanels.tsx
- components/scene/AreaInfoPanel.tsx
- components/scene/AreaPostSlider.tsx

### 変更してはいけないファイル
- app/globals.css
- IslandCanvas.tsx / IslandModel.tsx / Pin.tsx / Background.tsx
- ColumnBoard.tsx
- Header.tsx / Footer.tsx
- store/scroll-progress-store.ts
- WordPress側ファイル全て

### 絶対に守ること
- **PC(md以上)のレイアウト・構造を変えない**
- fixed 要素の位置指定プロパティを auto にしない
- 親の幅が未確定な状態で子に width: 100% を使わない
- エリア自動切替(activeAreaSlug 連動)の挙動を維持する

## セルフ検証

1. SP(390×844)でタブがカードの上にあるか確認
2. カルーセル左端にエリア情報カードがあるか確認
3. タブを Job → Event → Spot と切り替え、
   投稿カードのみ入れ替わることを確認
4. エリア情報カードが常に左端にあることを確認
5. 横スワイプで scroll-snap が効くか確認
6. PC(1440×900)で computed style が
   Task 08e-2 完了時点と同一か確認
