# Phase 5 Task 08g: SP時のカード幅・島の位置調整

## 修正項目

### 修正1: タブ付き投稿カードの右端の余白を解消

**現状**: カード右側に不要な余白があり、
次のカード(エリア情報カード)が中途半端に見切れている

**修正**:
- タブ付き投稿カードの幅を、次カードが適度にチラ見えする
  サイズに調整する(画面幅の85〜88%程度)
- カード右端に空白領域ができないようにする
- scroll-snap の吸着位置が正しく機能するようにする

### 修正2: SPでもサムネイル画像を表示できるようにする

**現状**: SPではサムネイル画像が表示されていない、
または領域が確保されていない

**修正**:
- 投稿カード内にサムネイル画像を表示する
- 画像が表示できる十分な幅と高さを確保する
- レイアウトは以下のいずれか(実装者判断):
  - 横並び(テキスト左・画像右)
  - 縦積み(画像上・テキスト下)
- 画像の aspect-ratio を維持する
- カード全体の高さが画面の35%を超えないこと

### 修正3: 3D島の位置とサイズ調整

**現状**: 島がやや下寄りで、サイズも小さめ

**修正**:
- 島をもう少し**上**に配置する
- 島をもう少し**大きく**する
- ただし島全体が画面内に収まることは維持する
- カード領域と重ならないこと

調整方法(実装者判断):
- カメラの position(y を上げる / z を近づける)
- カメラの fov
- IslandModel の group position / scale
