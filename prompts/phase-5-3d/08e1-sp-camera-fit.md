# Phase 5 Task 08e-1: SP時の島を画面内に収める

## 問題

SP表示で3D島が画面左に寄っており、右半分が見切れている。

## 目的

SP時に島全体が画面内に収まり、水平方向中央に表示されるようにする。

## 要件

- 島の左右端が画面内に入る
- 島が水平方向中央付近にある
- 島が縦方向でも見切れない
- 島のサイズは画面幅の80〜90%程度

## 実装方針

画面幅で分岐し、SP時のみカメラ設定または
IslandModel の position を変更する。

調整可能なパラメータ:
- カメラの position(x / y / z)
- カメラの fov
- IslandModel の group position
- IslandModel の group scale

どれをどう調整するかは実装者の判断に委ねる。

## 制約

### 変更してよいファイル
- components/scene/IslandCanvas.tsx
- components/scene/IslandModel.tsx

### 変更してはいけないファイル
- 上記以外すべて

### 絶対に守ること
- **PC(md以上)のカメラ設定・島の位置を1pxも変えない**
- 画面幅で分岐させ、SP時のみ別の値を使う
- スクロール連動回転の挙動を維持する

## セルフ検証

1. SP(390×844)で島の左右端が画面内に入っているか確認
2. PC(1440×900)で Task 08d 時点と同じ見え方か確認
3. スクロールで島が回転するか確認

## 受け入れ条件

- [ ] 島が水平方向中央付近にある
- [ ] PC(1440×900)の見た目が変わっていない
- [ ] スクロールで島が回転する
