# Phase 5 Task 08b: モバイル対応のレイアウト崩れ修正

## 発生している問題

Task 08 のモバイル対応実装後、PC・SP両方で
レイアウトが大きく崩れている。

### PC(1440×900)での症状
- サイドパネルが画面右下ではなく**左上**に表示されている
- Header とパネルが重なっている
- 3D島が画面下方に押しやられている

### SP(375×667)での症状
- 上記に加えて、テキストが**縦書き**になっている
  (幅が極端に狭くなり1文字ずつ折り返されている)
- パネル同士が重なっている

## 対応方針

**まず現状を Task 08 実装前の状態に戻してください。**

その上で、崩れの原因を特定してから、
段階的にモバイル対応を入れ直します。

## 手順

### Step 1: 現状のロールバック

git で Task 08 のコミットを確認し、
その直前の状態に戻してください。

git log --oneline -10

Task 08 のコミットが特定できたら:
git revert <commit-hash>
または
git checkout <前のcommit-hash> -- <対象ファイル>

ロールバック後、PC表示が Task 07b 完了時点の
正常な状態に戻ることを確認してください。

### Step 2: 崩れの原因を特定して報告

ロールバック前のコードを確認し、
以下のどれが原因だったか特定してください:

- position / top / right / bottom の指定ミス
- flex / grid の方向指定ミス
- width の単位ミス(% と vw の混同など)
- メディアクエリの記述ミス(min-width と max-width の逆)
- 親要素の display 変更による子要素への影響
- writing-mode の意図しない指定

**原因を特定するまで、再実装しないでください。**
原因が分かった時点で一度報告してください。

### Step 3: 再実装(原因報告後、別途指示します)

このタスクでは Step 1 と Step 2 のみ実施してください。
再実装は原因を確認した上で、次のタスクとして指示します。

## 制約

- 変更してよいファイル: Task 08 で変更したファイルのみ
- 3D関連ファイル(IslandCanvas / IslandModel / Pin / Background)は
  Task 08 で変更していないはずなので、触らない
- WordPress側ファイルは変更しない
