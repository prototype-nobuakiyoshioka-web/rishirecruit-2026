# Phase 5 Task 08f: SP時のカード構造をPC版と統一

## 問題

現在のSP表示では以下の問題がある:

1. カルーセルが投稿ごとに分割されており、
   タブで絞り込んだ投稿が1枚ずつ横に並んでいる
2. コラム看板がタブの右隣にあり、配置が不自然

## 目的

SP時のカード構造をPC版と同じにする。
横並びは「エリア情報カード」と「タブ付き投稿カード」の
**2枚のみ**にする。

## 目標構造

┌─────────────────────┐
│ │
│ 3D島 │
│ │
├─────────────────────┤
│ [コラム看板] │ ← タブの上に配置
│ ┌───┬─────┬─────┐ │
│ │Job│Event│Spot │ │ ← タブ
├──┴───┴─────┴─────┴──┤
│ ← [エリア情報][投稿] → │ ← 2枚のみ横並び
└─────────────────────┘


### 要件

| 項目 | 要件 |
|---|---|
| 横並びカード数 | **2枚のみ**(エリア情報 / タブ付き投稿カード) |
| 1枚目 | エリア情報カード(PC版と同じ内容) |
| 2枚目 | タブ付き投稿カード(PC版と同じ構造) |
| 投稿の切替 | 2枚目のカード**内部**でスライド(← ・・ → のナビ) |
| タブの位置 | 2枚目のカードの上部に付属 |
| コラム看板 | タブの**上**、カルーセル領域の上部に配置 |

### 重要な変更点

**現状**: 投稿ごとにカードを分割 → 横スクロールで投稿を切替
**目標**: 投稿カードは1枚 → **カード内部**のナビで投稿を切替

つまり PC版とまったく同じ構造で、
エリア情報カードとの間だけ横スクロールする形にする。

## セルフ検証

### 1. カード枚数の確認
SP(390×844)で横スクロールし、
カードが**2枚のみ**であることを確認する。
3枚目以降が存在しないこと。

### 2. 投稿切替の確認
2枚目のカード内で ← ・・ → のナビを操作し、
カード内部で投稿が切り替わることを確認する。

### 3. タブの確認
タブを Job → Event → Spot と切り替え、
2枚目のカードの内容が入れ替わることを確認する。

### 4. 看板の位置確認
コラム看板がタブの上に配置され、
島・タブ・カードと重なっていないことを確認する。

### 5. PC非デグレ確認
1440×900 で computed style が
Task 08e-3 完了時点と同一か確認する。
