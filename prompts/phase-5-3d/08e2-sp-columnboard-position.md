# Phase 5 Task 08e-2: SP時のコラム看板の位置調整

## 問題

SP表示でコラム看板が3D島と重なっている。

## 目的

看板を島と重ならない位置に移動し、
SP画面内で自然に配置する。

## 要件

- 3D島と重ならない
- タブ・カードと重ならない
- Header と重ならない
- SP時は看板のサイズを現在の60〜70%程度に縮小する
- タップしやすいサイズは維持する(最小44px)

## 配置イメージ

┌─────────────┐
│ 3D島 │
├─────────────┤
│[看板] [タブ] │ ← 看板をタブと同じ行に
├─────────────┤
│ カード │
└─────────────┘


看板をタブの左側、または近い位置に配置する。
具体的な配置は実装者の判断に委ねる。

## 制約

### 変更してよいファイル
- components/scene/ColumnBoard.tsx
- components/scene/AreaSidePanels.tsx(看板をこの中に含める場合のみ)

### 変更してはいけないファイル
- 上記以外すべて

### 絶対に守ること
- **PC(md以上)の看板の位置・サイズを変えない**
- 看板のクリックで /columns へ遷移する機能を維持する

## セルフ検証

1. SP(390×844)で看板が島・タブ・カードと重なっていないか目視
2. 看板をタップして /columns へ遷移するか確認
3. PC(1440×900)で看板が左下に元通り表示されるか確認

## 受け入れ条件

- [ ] SP(390×844)で看板が島と重なっていない
- [ ] SP(390×844)で看板がタブ・カードと重なっていない
- [ ] SP(375×667)でも同様
