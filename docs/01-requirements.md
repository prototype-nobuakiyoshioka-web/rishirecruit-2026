# 利尻富士町 3Dポップ求人ポータル 要件定義書

**Document version:** 1.0
**作成日:** 2026-05-20
**プロジェクトコード:** rishiri-3d-portal

---

## 1. プロジェクト概要

### 1.1 サマリー

利尻島を忠実にローポリ&ポップに3D化し、スクロール連動で島が左右に回転する没入感のあるインタラクティブサイト。島の象徴的なランドマークにピンを立て、**求人（利尻富士町行政職員）・イベント・観光地・コラム記事**へ導線を作る。

### 1.2 サイトの位置づけ

**民間運営の求人ポータルサイト**

| 項目 | 内容 |
|---|---|
| 制作・運営 | 1人体制（個人運営） |
| 求人情報の提供元 | 利尻富士町役場 |
| 行政連携 | 役場の公式サイトからリンクを貼ってもらう形 |
| 規制上の位置づけ | 自治体公式サイトではない → 表現の自由度を確保 |
| 信頼性の担保 | 行政提供の求人情報を扱うことで実情報の信頼性を確保 |

### 1.3 参考サイト

- **haru-ni.net** — 3Dポップな街の表現を参考にする

### 1.4 主要ゴール

**求人応募の獲得**（最重要KPI）

## 2. ターゲットユーザー

### 2.1 優先順位

| 順位 | 層 | 概要 |
|---|---|---|
| 1 | 移住検討者 | 本気で島に住むか考えている人 |
| 2 | 求職者 | 島で働ける場所を探している人 |
| 3 | 一般読者 | 島に興味があるファン・遠方の応援者 |
| 4 | 観光客 | 短期で島を訪れる人 |

### 2.2 ペルソナの主軸

- 20〜40代、地方移住に関心がある
- 都市部での生活に閉塞感や疲れを感じている
- 安定した職（行政職員）と自然豊かな環境を求めている
- Webリテラシーは平均的、スマホ閲覧が中心
- SNSや旅行系コンテンツでの「いいなぁ」体験から実際の移住検討に進む層

### 2.3 主要ユースケース

1. SNSやサイトからの流入で島の3Dビジュアルに触れ「面白そう」と感じる
2. ピンを巡って求人情報・島の暮らし・観光地の雰囲気を知る
3. コラム記事で具体的な暮らしの解像度を上げる
4. 求人モーダルで条件を確認し、問い合わせフォームで応募意向を送る

## 4. 機能要件

### 4.1 コンテンツ4種（カスタム投稿タイプ）

| ID | 投稿タイプ | 用途 | 想定件数 |
|---|---|---|---|
| `recruit` | 求人 | 利尻富士町行政職員の求人情報 | 数件〜十数件 |
| `event` | イベント | 島内のイベント情報 | 月数件 |
| `spot` | 観光地 | 島の観光地・名所情報 | 30件程度 |
| `column` | コラム | 記事コンテンツ（暮らし・働く人インタビュー等） | 月1〜2本ペース |

#### 共通フィールド

- タイトル、本文、サムネイル画像
- ピン位置情報（3D座標 X/Y/Z または緯度経度）
- 公開日、最終更新日
- カテゴリ別固有フィールド（詳細は `content-schema.md` で別途定義）

### 4.2 3Dインタラクティブマップ

#### 4.2.1 表示

- 利尻島全島を3Dローポリで表現（東側=利尻富士町中心だが、島全体を作る）
- ポップな配色（フラットシェーディング、単色マテリアル基本）
- 海に囲まれた島感を強調
- 中央に利尻富士（利尻山）

#### 4.2.2 必須ランドマーク

- ✅ 利尻富士（利尻山）の山頂シルエット
- ✅ 鴛泊港・フェリーターミナル（島の玄関口）
- ✅ 姫沼（利尻富士を映す人気の湖）
- ✅ オタトマリ沼（鬼脇地区の名所）
- ✅ ペシ岬（鴛泊の岬）

#### 4.2.3 カメラ操作

- **スクロール連動回転**: ページスクロールに応じて島が左右に回転
- **回転範囲制限**: 左右各45°程度（±π/4）
- スムースな慣性付き（イージング適用）
- 範囲を制限することで、島の裏側のモデリングを省略可能

#### 4.2.4 ピン

- 4種コンテンツそれぞれにカテゴリ別のピン色・アイコン
- カメラに常に正面を向く（Billboard処理）
- クリック/タップで詳細モーダル表示
- カテゴリ別フィルタ機能（任意のピン種類のみ表示）

#### 4.2.5 モーダル

- ピン情報の詳細表示
- 求人モーダルにはCTAボタン → 問い合わせフォームへ誘導
- レスポンシブ（SPでは下からスライドするボトムシート形式）

### 4.3 問い合わせ・応募意向フォーム

- 求人ピンモーダルから遷移
- **入力項目**: 氏名、メールアドレス、電話番号（任意）、応募希望職種、メッセージ
- **送信先**: 運営者と役場の両方にメール通知
- スパム対策（hCaptcha または reCAPTCHA）
- 送信後のサンクスページ表示

### 4.4 動的ページ

- コラム記事は個別ページを持つ（Next.js動的ルート）
- SEO対応のメタデータ生成（OGP、Twitter Card、Schema.org）
- ソーシャルシェアボタン

### 4.5 管理機能（WordPress側）

- 4CPTの管理画面UI
- **ピン座標入力UIの工夫**: 管理者1人でも扱いやすい仕組み（マップピッカー or 別管理画面）
- メディア管理（画像最適化プラグイン）

## 5. 非機能要件

### 5.1 パフォーマンス

| 指標 | 目標値 |
|---|---|
| LCP（PC・SP両方） | < 2.5秒 |
| GLBファイルサイズ（フル版） | ≤ 5MB |
| GLBファイルサイズ（モバイルLOD版） | ≤ 2MB |
| 総ポリゴン数 | ≤ 10万 |
| Lighthouse Performance | ≥ 80（PC）、≥ 60（モバイル） |

### 5.2 対応環境

- **ブラウザ**: 最新版のChrome / Safari / Firefox / Edge
- **モバイル**: iOS Safari、Android Chrome実機テスト必須
- **解像度**: PC 1366px〜4K、タブレット、スマホ 375px〜
- **モバイル3D方針**: 軽量版GLB + dpr制限で**3D維持**（2Dフォールバックなし）

### 5.3 SEO

- 各コラム記事の個別ページ + メタデータ
- サイトマップ自動生成
- 構造化データ（Article、JobPosting）
- robots.txt 適切設定

### 5.4 アクセシビリティ

- 自治体公式サイトではないため JIS X 8341-3への厳格準拠は不要
- ただし**基本的な配慮**は行う:
  - 色のコントラスト比 WCAG AA 相当
  - altテキストの記載
  - キーボード操作可能なUI
  - フォームのラベル付け
  - 3Dが見られない環境向けに、テキスト形式での求人一覧ページも別途用意

### 5.5 セキュリティ

- WP管理画面はIP制限またはBASIC認証
- フォームのスパム対策（hCaptcha等）
- HTTPS（SSL）必須
- WPコア・プラグインの定期更新
- 環境変数による秘匿情報管理

### 5.6 監視・分析

- GA4設置
- Vercel Analytics（必要に応じて）
- WP編集ログ
- フォーム送信失敗の検知（必要に応じてSentry等）

## 6. デザイン要件

### 6.1 トンマナ

**ポップ・カラフル全開**（明るさ重視、haru-ni風）

求人ポータルでありながら、堅実な求人サイトと真逆の方向性で差別化を図る。「島で働くって楽しそう」と感じさせ、ハードルを下げる効果を狙う。

### 6.2 ブランド方針

| 項目 | 状況 |
|---|---|
| サイト名 | **未定**（要件定義後に決定） |
| 独自ロゴ | **未定** |
| ドメイン | **未定** |
| 利尻富士町公式ロゴ | 「求人提供元」として併用予定 |
| 配色基調 | 海・山・空・夕日 をモチーフにしたポップパレット |

詳細なカラーパレット・デザイントークンは `design-tokens.md` で別途定義予定。

### 6.3 UI原則

- 3Dマップが主役、UIは脇役
- ピン情報の可読性を最優先
- モーダルや読み物は落ち着いた可読性
- 求人モーダル内は信頼感を演出（役場提供情報部分の質感を引き締める）

### 6.4 タイポグラフィ方針（暫定）

- **日本語**: 丸ゴシック系（M PLUS Rounded 1c、Zen Maru Gothic候補）
- **欧文**: 親しみあるサンセリフ + アクセントにFraunces等のセリフ
- （詳細は `design-tokens.md` で定義）

## 7. 制約・前提条件

### 7.1 体制

- 制作・運営とも**1人体制**
- 主担当者の特性: デザイン感覚あり、AI主体のコーディング、3Dは初挑戦（ただしBlender着手済）

### 7.2 スケジュール

- ローンチ希望時期: **半年以内**（じっくり方針）
- Blender学習を要件定義と並行で開始
- **Phase 2開始から3週間時点でチェックポイント**: 利尻富士の形が出ていなければ外注（B案）に切替

### 7.3 予算

| 項目 | 想定額 |
|---|---|
| 月額運用コスト | 1〜3万円以内 |
| WPホスティング | 3,000〜5,000円 |
| ACF Pro等プラグイン | 1,000円/月換算 |
| Vercel | 無料 or Pro（3,000円） |
| 残り予算 | 3D素材購入・CDN・画像最適化等の予備 |

### 7.4 技術スタック（確定）

| レイヤー | 採用技術 |
|---|---|
| フロントエンド | Next.js 14 (App Router) + TypeScript |
| 3D描画 | React Three Fiber + drei + Three.js |
| スクロール | Lenis |
| 状態管理 | Zustand |
| データ取得 | TanStack Query + GraphQL Codegen |
| バックエンド | WordPress（ヘッドレス）+ WPGraphQL + ACF Pro |
| 3Dモデリング | Blender → glTF/GLB（Draco/Meshopt圧縮） |
| ホスティング（フロント） | Vercel |
| ホスティング（WP） | Kinsta / WP Engine / Cloudways（未確定） |

### 7.5 既存資産

- ✅ 利尻島の写真・動画（自身撮影 または使用許可取得済み）
- ✅ 利尻富士町公式素材・ロゴ（使用予定）
- ✅ Blenderで島の地形ベースを試作済（Displace + Decimateで山部分作成）

### 7.6 法的・運用上の前提

- 民間運営のため、自治体特有の規制対象外
- 求人情報の正確性は役場提供時の内容を信頼
- **プライバシーポリシー必須**（フォーム経由で個人情報を収集するため）
- 特定商取引法表記の検討（求人ポータルとしての立て付け次第）

## 8. スコープ外（やらないこと）

このリリース範囲では以下を**含めない**。将来のフェーズで検討する場合は別途要件化する。

- ❌ **多言語対応**（英語等）→ 日本語のみ
- ❌ **ニュースレター登録・メルマガ配信**
- ❌ **ユーザー会員登録・マイページ機能**
- ❌ **イベント参加申込フォーム**（応募フォームと別物として混同を避ける）
- ❌ **物販・EC機能**
- ❌ **リアルタイムチャット・問い合わせbot**
- ❌ **2Dマップへのフォールバック**（モバイルも3D維持）
- ❌ **自治体公式サイトの代替**（あくまで求人ポータル）
- ❌ **島の裏側（回転制限外）の精密モデリング**（工数削減）
