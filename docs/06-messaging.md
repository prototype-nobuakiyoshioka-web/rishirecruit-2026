## 1. 概要

本ドキュメントはリシリクルートの全コピー・メッセージング方針を定義する。

**メッセージングの世界観:**
- 「リシリクルートは「単なる求人サイト」ではなく**「人生の選択肢に気づく場所」**として位置づける」
- 利尻島は「主役」ではなく**「選択肢のひとつを体現する具体例」**として扱う
- 視座は高く、表現は素朴に、行動は具体的に

## 2. メインキャッチコピー（タグライン）

### 2.1 確定タグライン

```
行き先は、自分で決める。
```

### 2.2 サブコピー

```
利尻富士のふもとで、新しい仕事と暮らしを。
```

### 2.3 タグラインの意図

| レイヤー | 意味 |
|---|---|
| 表層 | 仕事を選べる（求人サイトとしての機能） |
| 中層 | 暮らす場所を選べる（移住の文脈） |
| 深層 | 人生の方向性を自分で決められる（哲学・主体性） |

この三層構造により、訪問者は自分の関心の深さに応じてメッセージを受け取れる。

### 2.4 補助メッセージ（コンテキスト別）

タグラインを補助する短いコピー:

| 場面 | コピー |
|---|---|
| ロゴ + 一言補助 | 北海道・利尻富士町の求人ポータル |
| SNSシェア時 | 行き先は、自分で決める。利尻富士町の求人を、3D地図で。 |
| 名刺・印刷物 | 利尻富士町の暮らしと仕事を、ここから。 |
| メール署名 | リシリクルート — 行き先は、自分で決める。 |

## 5. CTAラベル

### 5.1 主要CTA

| 用途 | ラベル | 配置 |
|---|---|---|
| **応募する** | 求人詳細ページの固定CTA | 画面下部・サイドバー固定 |
| 詳細を見る → | 求人カード/モーダル | 各カード末尾 |
| リストで求人を見る → | Home から `/jobs` | 3Dマップ下の副次CTA |
| この島で働く → | `/spots` → `/jobs` | スポット詳細末尾 |
| 求人を見る → | `/columns` → `/jobs` | コラム一覧末尾 |
| 募集中の仕事を見る → | `/message` → `/jobs` | メッセージページ末尾 |
| お問い合わせ | フッターなど | 通常リンク |

### 5.2 CTAの視覚仕様

主要CTA（「応募する」）:
- 色: 夕陽コーラル（#FF7B5B）背景 + 白文字
- 形状: ピル型（border-radius: 9999px）
- シャドウ: `--shadow-pop-coral`（押せる感）
- サイズ: 最低44×44pxのタップ領域

副次CTA・テキストリンク:
- 色: 海の青（#1B5F8C）文字 + 矢印 `→`
- ホバー時: 下線が現れる
- パンくず的に控えめに

### 5.3 「応募する」を採用した理由

- 慣習的でクリア（応募率に影響する）
- 「行き先を決める」等のブランド造語をCTAに使うと混乱を招く
- ブランド世界観は周辺コピーで担保する

## 6. ボイス&トーン定義

### 6.1 Voice（変わらない人格）

サイト全体を通じて一貫する声の特徴:

| 特徴 | 説明 |
|---|---|
| 落ち着いた確信 | 押しつけがましくない、でもブレない |
| 主体性を尊重 | 「あなたが決める」が根底にある |
| 視座が高い | 仕事だけでなく暮らし・人生まで含めて語る |
| 地に足がついている | 抽象論で終わらず、具体的な情報も出す |
| 短文・「、」のリズム | 長文を避け、句読点で呼吸を作る |
| ひらがな多め | 漢字は知性、ひらがなはやさしさ |
| 二人称で直接アドレス | 「あなた」「自分」を恐れず使う |

### 6.2 Tone（場面で変わる温度）

文脈に応じて温度を変える:

| 場面 | トーン | 例 |
|---|---|---|
| ヒーロー領域 | 力強く・宣言的 | 「行き先は、自分で決める。」 |
| 本文・説明文 | 穏やか・説明的 | 「利尻富士町は、北海道最北の島です。」 |
| CTA | 簡潔・明確 | 「応募する」 |
| エラー表示 | シンプル・標準的 | 「入力してください」 |
| 完了メッセージ | あたたかい安堵 | 「届きました。」 |
| 法的文書 | 正確・無感情 | 「個人情報の利用目的は次のとおりです。」 |
| 季節挨拶 | 季節感・詩的 | 「春の利尻島に、ようこそ。」 |

## 7. NG表現

ブランドの世界観を壊す表現はサイト全体で禁止:

| NG | 理由 |
|---|---|
| 「夢を叶える」 | 陳腐、ブランドの素朴さと合わない |
| 「絶対」「必ず」 | 押しつけ感が強い |
| 「あなたを変える」 | 主語が逆（「自分が決める」軸と矛盾） |
| 「人生最後の」 | 過度な煽り |
| 「奇跡」「魔法」 | 安易な誇張 |
| 「衝撃の」「驚愕の」 | 釣り見出し感 |
| 顔文字・絵文字の連発 | ブランドトーンと不整合 |
| 「!」「!!」の多用 | 騒がしさ、信頼感の毀損 |
| カタカナビジネス用語 | 「シナジー」「コミット」「ジョイン」等 |
| 「皆さま」「弊サイト」 | 過度な敬語、距離感を生む |
| 「ぜひ」の連発 | 押しつけ感 |
| 自己卑下表現 | 「拙い」「至らない」等は不要 |

## 9. /message ページの本文方向性

### 9.1 ページの位置づけ

- 「町長メッセージ」のような硬さではなく、**「町の人からのちょっとしたお手紙」**
- 読み手と書き手が同じ目線で、まっすぐ語りかける
- ブランドの「視座が高く、表現は素朴」を最も体現するページ

### 9.2 構成案（章立て）

1. **挨拶**（やぁ感）
   - 「こんにちは。利尻富士町からです。」のような、肩ひじ張らない出だし
2. **利尻富士町ってどんな町**
   - 場所、人口、自然、産業をシンプルに
   - 「日本最北の有人離島のひとつ」程度の事実から入る
3. **なぜ今、新しい仲間を募集しているのか**
   - 正直に語る（人口減少・高齢化等を隠さない）
   - でも前向きに（だからこそ来てくれる人を待っている）
4. **どんな人と一緒に働きたいか**
   - 「行き先を自分で決められる人」という軸
   - 具体的なスキルより、姿勢・価値観
5. **移住者へのサポート体制**
   - 住居・補助金・相談窓口
   - 単発のサポートじゃなく、長期的に伴走する姿勢
6. **結び**
   - 「あなたの「次」の選択肢のひとつに、ぜひこの島も加えてください」
   - 押しつけず、選択肢として置く

### 9.3 文体ルール

| 項目 | ルール |
|---|---|
| 書き手の一人称 | **「私たち」**（町の人として） |
| 読み手の二人称 | **「あなた」** |
| 語尾 | です・ます調基本、たまに「。」を外す |
| 段落の長さ | 短め（2-3文で改行） |
| 句読点 | 全角の「、」「。」 |
| 文字数目安 | 全体で1500-2500字 |
| 改行・余白 | 読みやすさ優先で多め |

### 9.4 本文サンプル（書き出し）

```
こんにちは。利尻富士町からです。

このページを開いてくれて、ありがとうございます。
あなたが「次の行き先」を探しているなら、すこしお話しさせてください。

利尻富士町は、北海道の北の方の、海に囲まれた小さな町です。
利尻富士という美しい山と、深い青の海と、雪化粧の冬と、若緑の夏が、
わたしたちの日常をつくっています。

人口は2,000人弱。
これからもう少し、新しい仲間に来てもらえたらと思っています。
...
```

## 12. 実装時の運用ルール

### 12.1 句読点・記号

- 全角の **「、」「。」** を使う
- 「!」「?」は **半角** で統一
- 三点リーダーは **「...」**（半角ピリオド3つ）
- カッコは原則 **「」** を使い、英数字には半角 `()` も可
- ダッシュは **「—」** (em dash) を使う

### 12.2 数字表記

- 1〜10は **半角**: 1人、3営業日、19件
- 11以上も **半角** が基本: 2,000人
- 「ひとつ」「ふたつ」など擬人化・口語的な時は漢字でOK

### 12.3 英単語の扱い

- カタカナ表記が定着しているもの: カタカナ（コラム、メッセージ、フォーム）
- 固有名詞・サービス名: 英字（Note、WordPress）
- 半角英数字と日本語の間にスペースは入れない（CSS側で文字間隔調整）

### 12.4 文字数の目安

| 場面 | 文字数目安 |
|---|---|
| メインタグライン | 8-12文字 |
| サブタグライン | 15-25文字 |
| ヒーロー（ページ別） | 8-15文字 |
| ヒーローサブ | 20-30文字 |
| 段落 | 1段落2-4文 |
| ボタンラベル | 4-7文字 |
| meta description | 80-150文字 |

### 12.5 アクセシビリティ配慮

- 「クリック」「タップ」を混在させず、共通の表現を使う（推奨: 「クリックしてください」）
- 装飾的な記号（「→」等）は読み上げで邪魔にならないか確認
- 重要なメッセージは色だけに依存しない
