参考コードパターン — Code Patterns

主要な処理の雛形。AIに質問するときに「これをベースに〜」と一緒に貼ると、回答の精度がぐっと上がります。

scene.tsx — Scroll-controlled rotation with clamp + damp
// Phase 5: スクロール進捗 → 島の回転（範囲制限あり）
import { useRef } from "react";
import { useFrame } from "@react-three/fiber";
import { useScroll } from "@react-three/drei";
import * as THREE from "three";

export function Island({ gltf }) {
  const ref = useRef<THREE.Group>(null);
  const scroll = useScroll();
  const MAX = Math.PI / 4; // 左右45°

  useFrame((_, dt) => {
    if (!ref.current) return;
    const p = scroll.offset; // 0..1
    const target = THREE.MathUtils.clamp(
      (p - 0.5) * 2 * MAX, // -MAX..+MAX
      -MAX, MAX
    );
    ref.current.rotation.y = THREE.MathUtils.damp(
      ref.current.rotation.y, target, 4, dt
    );
  });

  return <primitive ref={ref} object={gltf.scene} />;
}

プロジェクト全体の落とし穴 — Common Pitfalls

WP / CORS
CORS設定漏れでAPI叩けない
functions.phpで本番ドメインに対する Allow-Origin ヘッダを設定
WP / Preview
ヘッドレスでプレビューが動かない
Next.js Draft Mode + WP側プレビュー用エンドポイントを実装
3D / MIME
GLBのMIMEがoctet-streamでキャッシュ非効率
ホスティング側で model/gltf-binary を設定
3D / iOS
iOS Safariで3Dがカクつく/落ちる
dpr下げ、影オフ、ポストエフェクト削減、LODモデル使用
Scroll
Lenisとnative scrollが干渉
Lenisに一元化、ScrollTrigger等は同期させる
3D / Easing
回転制限とイージングが噛み合わずカクつく
clamp で角度制限後に damp で慣性をつける順序
Operation
ピン座標を編集者が手入力できない
専用マップピッカーUIか別JSONで管理
Performance
ピンが多いとHTMLオーバーレイで重い
Spriteベースに切替、視錐台外を非表示

用語集 — Glossary

ヘッドレスCMSheadless CMS
表示テンプレを持たず、コンテンツをAPIで提供するCMSの使い方。WPはAPI、フロントは別フレームワーク。
React Three FiberR3F
three.jsをReactコンポーネント感覚で書けるライブラリ。シーン構築が宣言的になる。
drei@react-three/drei
R3Fのユーティリティ集。useGLTF、Html、useScroll など本プロジェクトでも多用。
glTF / GLB3D file format
Webの標準的な3Dフォーマット。GLBはバイナリ版で1ファイルにまとめられる。
LODLevel of Detail
距離・端末に応じてモデルの精度を切り替える手法。本プロジェクトはモバイル軽量版で使う。
Draco / Meshoptcompression
glTFのジオメトリ圧縮方式。ファイルサイズを大幅に削減できる。
Lenissmooth scroll
滑らかなスクロールを実現するライブラリ。3D連動と相性が良い。
WPGraphQLWP plugin
WPコンテンツをGraphQLで取得できるようにするプラグイン。REST APIより型安全。
ACFAdvanced Custom Fields
WPに任意フィールドを追加するプラグイン。ピン座標などのカスタム情報を保持。
Billboard3D技法
カメラに常に正面を向ける表示手法。ピンや看板に使う。
Core Web VitalsCWV
GoogleのWebパフォーマンス指標（LCP / CLS / INP）。SEOにも影響。
Draft ModeNext.js
Next.jsの下書きプレビュー機能。ヘッドレスWPと組み合わせて使う。
