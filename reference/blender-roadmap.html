到達したいゴール

「リシリクルートの3Dマップとして実際にブラウザで動く」状態がゴール。 リアル寄りではなく、シンボル性のあるローポリ&ポップで、利尻島の象徴的要素（利尻富士・海・主要ランドマーク）が一目で伝わるモデルを作る。

island.glb
デスクトップ用フル版。3層メッシュ分離済みで季節色を動的に変更できる。
≤ 5MB 5〜10万ポリ Draco圧縮
island-mobile.glb
モバイル用LOD版。ポリ数とディテールを大幅削減した軽量版。
≤ 2MB ≤ 2万ポリ Meshopt推奨
合格基準 / Quality criteria
  • 形式: glTF 2.0 / GLB（バイナリ）
  • シェーディング: 全面 Flat Shading（ローポリ感を強調）
  • テクスチャ: 不使用、Vertex Color または マテリアル単色のみ
  • メッシュ構造: 山頂・中腹・麓・海面・ランドマークが独立メッシュ
  • マテリアル: 山の3層は別マテリアル（季節色変更のため必須）
  • 識別性: 利尻富士のシルエット + 主要4ランドマーク（姫沼・オタトマリ沼・ペシ岬・鴛泊港）が見える

6ステップの道のり — 6-Step Production Path

01

基礎セットアップ

Foundation 1〜2週間
Blender操作の基礎を身につけ、簡単な作品を一つ完成させる。利尻島に取りかかる前の「足場固め」。
  • Blender最新版インストール（5.x系推奨、現在使用中の5.1.1でOK）
  • Blender Guruの「ドーナツチュートリアル」を最後まで完走
  • Grant Abbitt の「Low Poly Beginner」シリーズで低ポリ感覚をつかむ
  • ショートカット: G 移動 / R 回転 / S スケール / Tab モード切替を体に覚えさせる
必要スキル オブジェクト操作 · Edit Mode · モディファイア概念 · マテリアル基本 · レンダリング
アウトプット ドーナツ作品1点 · Blender画面の「迷子」状態を脱出
落とし穴

このフェーズで「完璧に理解」しようとしないこと。8割わかれば十分。手を動かしながら覚える方が早い。

02

地形ベース作成

Terrain Foundation 1週間
「四角い板に山が突き出ている」状態から「海に囲まれた島」に進化させる。
  • 国土地理院DEMから利尻島の標高データを取得（数値標高モデル 5mまたは10mメッシュ）
  • QGISでGeoTIFF → グレースケールPNG（16bit）に変換
  • BlenderでPlane作成 → Subdivide → Displace モディファイア
  • 島の輪郭を Boolean で円形に切り抜き、または海面プレーンでマスク
  • 海面プレーンを島より少し下に配置（深海ブルー #0A2E4E）
必要スキル Displace · Boolean · Subdivide · QGIS基礎 · DEM変換
アウトプット 海に囲まれた島の形ができる · 利尻富士のシルエット出現
落とし穴

フリー素材のハイトマップを使うと利尻島の比率が狂う。国土地理院の正式データを使えば一発で「忠実な利尻島」が手に入る。

03

山の3層メッシュ分離

Layer Separation 1〜2週間
季節色変更を実現するため、山頂・中腹・麓を別メッシュに分割する。後からの修正は地獄なので、ここを丁寧に。
  • Edit Modeで標高により頂点を選択（例: 山頂=Z軸高さ800m以上）
  • P キー → "Selection" でメッシュを分離（Peak / Mid / Base）
  • 各メッシュに別マテリアル割り当て（peak / mid / base）
  • 春パレットの色をデフォルトに設定（#E8E4DA / #6FA66F / #9FCB85）
  • 各マテリアルの名前を統一規則で（コード側で参照しやすく）
必要スキル 頂点選択 · メッシュ分離 (P) · マテリアル割り当て · 命名規則
アウトプット 3つの独立メッシュ + 3つの別マテリアル · 季節変更の下準備完了
落とし穴

分離せず1メッシュのまま進むと、Phase 5以降で「季節色が変えられない」と気づいて全部やり直しに。このステップを必ず通過すること。

04

ランドマーク追加

Landmarks 1週間
「これは利尻島だ」と一目でわかる象徴的要素を最小限の手数で配置する。
  • 姫沼: 利尻富士中腹に小さな青い円形プレーン（#5BB4E0）
  • オタトマリ沼: 鬼脇エリアに同様の青い水面
  • ペシ岬: 北側海岸に小さな凸部 + 灯台代わりの白いキューブ
  • 鴛泊港: フェリー桟橋のシンプルな板
  • 利尻空港: 滑走路を表すフラットな帯（任意）
  • 各ランドマークの位置に Empty を配置（後でピン座標の参考に）
必要スキル 基本オブジェクト追加 · Empty · スナップ機能 · オブジェクト整理（Collection）
アウトプット 5つの主要ランドマーク + Empty による位置マーカー
落とし穴

ディテールを追いすぎないこと。「灯台」は白い小さな立方体で十分、屋根や扉まで作らない。ローポリの本質は「最小限の形で印象を残す」こと。

05

スタイル適用（ローポリ化）

Stylization 1週間
スムーズな地形を「カクカクのローポリ」に変換し、ポップな配色を確定する。
  • Decimate モディファイアを島メッシュに適用（Planarモード推奨）
  • 各メッシュの全頂点選択 → 右クリック → Shade Flat
  • マテリアル色の最終調整（4季節分のカラーを各マテリアルに保存）
  • 必要なら低ポリの木・雲・波の凹凸などの装飾を追加
  • ライティングをベイク（任意、ランタイム軽量化目的）
必要スキル Decimate モディファイア · Shade Flat · マテリアルプロパティ
アウトプット ローポリ&ポップな利尻島 · ポリ数10万以下に収束
落とし穴

Decimateのratioを下げすぎると山が「ペラペラの板」になる。0.3〜0.5で様子を見ながら段階的に減らすのが安全。

06

書き出しと最適化

Export & Optimize 1週間
Webブラウザでサクサク動くglbファイルを完成させる。最後の関門。
  • 全オブジェクト選択 → Object > Apply > All Transforms
  • File → Export → glTF 2.0 で書き出し（Format: GLB Binary）
  • コマンドライン: gltf-transform draco island.glb island-draco.glb
  • ファイルサイズ確認（5MB以下を目標）
  • glTF Viewer でブラウザ確認
  • モバイル用LOD版を別途書き出し（Decimateをさらに強めて）
  • PIN_POSITIONS用に主要ランドマークの座標を記録
必要スキル glTF Export設定 · Apply Transforms · CLIツール · ブラウザ確認
アウトプット island.glb + island-mobile.glb · 座標リスト · 完成！
落とし穴

Apply Transformsを忘れるとブラウザで位置がズレる。書き出し直前に必ず実行。

考え方の核5つ — The Big Five Mindset

シンボル性 > リアルさ

利尻富士「らしさ」が伝わればOK。地理的に正確である必要はない。象徴を抽出する。

完璧主義は捨てる

v1は粗くてもいい。出来た時点でWeb確認、改善は後追い。リリース後も磨ける。

メッシュ分離は最初から

山頂・中腹・麓は最初から別メッシュにする。後からの分割は本当に地獄。

テクスチャを使わない

Vertex ColorかMaterial Colorだけで構成。容量が10倍違う。

早く・何度も書き出す

Phase 5まで待たない。Phase 2-3でも一度glb化してWebで確認する習慣を。
